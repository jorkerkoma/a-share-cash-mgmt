# A股上市公司现金管理监测平台

覆盖 **沪市 + 深市 + 北交所** 全部 A 股上市公司近 3 个月发布的「现金管理 / 委托理财 / 购买理财产品 / 结构性存款」公告，支持**本次新购 + 到期赎回同表展示**、自动标注 **已到期 / 存续中 / 已到期赎回 / 随时可转让或赎回**、自动拆分 **银行 / 券商 / 具体分支行**，并提供 **本地 Web 多维筛选看板 + 一键导出样式化 Excel**。

> **零硬盘占用说明**：程序通过巨潮资讯网接口在线将 PDF 读入内存实时解析，提取结构化数据写入本地 SQLite 后立刻释放内存，**本地不保存任何 PDF 原文件**；每条记录保留官方原文 PDF 链接，点击即可浏览器在线核对。

---

## 快速使用

### 1. 启动本地 Web 分析平台
- 直接双击文件夹里的 **`启动平台.bat`**，或在终端运行：
  ```powershell
  "C:\Users\Admin\AppData\Local\Python\bin\python.exe" start_platform.py
  ```
- 浏览器会自动打开 `http://127.0.0.1:8000`
- 支持多维组合筛选、快捷状态标签（存续中 / 已到期 / 未来30天即将到期 / 仅看披露具体分行）、银行/券商/分行排行榜、上市公司采购排行、在线一键增量更新，以及一键导出当前筛选结果或全量 Excel。

### 2. 直接查看已生成的 Excel 汇总表
- 自动产出位置：`d:\企业理财产品\output\A股现金管理近3个月汇总_YYYYMMDD.xlsx`
- 内含 5 个工作表：
  1. `现金管理明细总表`（新购 + 到期赎回合表，高亮标明已到期，附可点击 PDF 链接）
  2. `未来30天即将到期`（按到期日升序，便于追踪大额即将到期资金）
  3. `银行与券商吸金排行`
  4. `上市公司购买排行`
  5. `待复核公告清单`

### 3. 命令行手动增量更新
```powershell
# 增量拉取近3个月最新公告并更新 Excel
"C:\Users\Admin\AppData\Local\Python\bin\python.exe" run_sync.py

# 指定日期范围同步
"C:\Users\Admin\AppData\Local\Python\bin\python.exe" run_sync.py --date-from 2026-11-01 --date-to 2026-11-30
```

### 4. 免费上云与每日自动更新（方案 3）
已内置纯静态云端打包脚本（`build_static.py`）、PC + 手机端响应式页面、以及 GitHub Actions 每日自动同步配置（`.github/workflows/daily-update.yml`，每天北京时间 21:30 与 08:30 自动更新）。
详细部署步骤（含国内手机免翻墙秒开的腾讯云 EdgeOne Pages 免费配置）请查看 **`上云部署指南.md`**。

### 5. 可选：启用大模型兜底解析
默认使用纯本地高精度 PDF 表格 + 正文规则引擎（零 API 费用）。如后续希望接入 MiniMax / DeepSeek / OpenAI 等兼容 API 对极少数非标准排版公告自动补录，可复制 `.env.example` 为 `.env`，填入有效的 `LLM_API_KEY` 并将 `LLM_ENABLED=true` 即可。
